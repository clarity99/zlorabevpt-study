# Moč v pomagajočih poklicih - študijski komplet

Statični študijski komplet za ustni izpit iz knjige *Power in the Helping Professions*.

## Vsebina

- Pregled knjige
- Podrobni povzetki poglavij
- Opombe med branjem
- Interaktivne kartice
- Ustna izpitna vprašanja
- Klinične povezave
- 9-dnevni načrt učenja

## Lokalni zagon

Odpri `index.html` ali zaženi:

```bash
python3 -m http.server 8765
```

Nato odpri `http://127.0.0.1:8765/study/index.html`.
